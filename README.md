# GradeManager

A simple Java program to manage and calculate student grades based on multiple subjects.

## Features
- Input student name
- Input marks for multiple subjects
- Calculate total and average marks
- Display the grade based on average
  - A: 90-100
  - B: 80-89
  - C: 70-79
  - D: 60-69
  - F: Below 60

## How to Run
1. Download the repository.
2. Open a terminal/command prompt in the project folder.
3. Compile the program:
   ```bash
   javac GradeManager.java
   java GradeManager
4.That's it your code is ready to run.
